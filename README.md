# Neon Particle Sandbox

Your mouse is now a lightning storm. A dark-mode canvas where every movement leaves glowing neon sparks and every click detonates a shockwave with its own synth blast.

## How to use it

- **Move the mouse** to leave a trail. Faster movement means bigger bursts.
- **Click** to trigger a shockwave, a particle explosion, a screen shake and a random synth sound.
- **Hold Space** to turn your cursor into a black hole that pulls particles in.
- **Glitch** adds sliced, shifting screen tearing and harsher square-wave sounds.
- **Sound on/off** mutes the synth. **Clear** wipes the canvas.

## Secret features

- Sound is generated live with the Web Audio API, with no audio files.
- Click sounds get a random pitch every time, so no two explosions sound the same.
- Three `console.assert()` tests run on load. Open the Console to check them.
